# Luckfox Lyra Zero W - 3寸 MIPI 屏幕设备树与 PCB 文件

[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)
[![GitHub repo size](https://img.shields.io/github/repo-size/SUNO-29/luckfox-lyra-zero-w-mipi-dsi-st7701s-3inch)](https://github.com/SUNO-29/luckfox-lyra-zero-w-mipi-dsi-st7701s-3inch)

本仓库为 **Luckfox Lyra Zero W** 开发板提供 **3寸 MIPI 屏幕**（驱动 IC：ST7701S）的设备树（Device Tree）源文件及配套 PCB 设计文件。

---

## 📁 仓库内容

- `rk3506-luckfox-lyra-ultra.dtsi` —— 设备树文件
- `rk3506b-luckfox-lyra-zero-w.dtsi` —— 设备树文件
- `PCB/` —— 屏幕转接板 PCB 源文件
